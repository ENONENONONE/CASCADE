Terminal commands

Six keydown listeners share the single input line. The base handler, registered first, is a bubble-phase listener. Five later handlers (hardware bridge, settlement, mesh and analysis, model bridge, NPU) are capture-phase listeners, and on the target element capture listeners run before bubble listeners, so every add-on handler gets first refusal and returns after stopImmediatePropagation. Among the add-ons, registration order decides. Three consequences are visible from the keyboard:

  • TOWER alone reaches the Fermat layer tower in the analysis handler; the base handler's Galois tower answers only TOWER k with a number.
  • TAPE alone reaches the hardware-bridge handler's tape-structure readout for the current position; the phonograph answers every TAPE <sub> form.
  • HANDSHAKE with a network name and a hex key goes to settlement; HANDSHAKE 72 with a field value goes to NanO₂. SEND text with hardware connected and an identity active is signed on the device; otherwise it is the NanO₂ send.

Anything unmatched is treated as a word lookup: exact match first, then substring, and the machine navigates there. A bare number 0–256 navigates directly and prints the position's dlog, inverse and fold.
