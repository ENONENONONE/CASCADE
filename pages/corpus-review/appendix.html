The tunnel chain in glyphs

Π = Φ∂ identity → Π×T = εQ transference → χ = ⅗⊗ opening → 𝟙𝟙 = ψΩ closure → W = δQ carrier. In numbers: 1 → 140 → 117 → 234 → 55, and 55 is the composite for any starting Γ.

Prepared from a complete read of the directory on 2026-09-04. Arithmetic was recomputed in Python from the definitions in the files; π digits were generated independently with a Machin formula to 4000 places. Private key material was read for the review and appears nowhere in this document.

The cards in glyphs

The charset turns any hex identifier into glyphs, one per nibble, so the MI25 identifiers read on 2026-09-05 (mi25_readout.md in the directory) can be written in the genome's own alphabet, and a palindrome of glyphs is a palindrome of hex digits. Under each string is the group of each nibble: m for MATH 0–7, e for ERROR 8–9, w for WAVE A–D, c for CLOSE E–F. Every rendering was regenerated from the hex; none of the identifiers is a palindrome in glyphs or in groups.
