I. The Cayley Transform — Polarizability and Reflection

Both frameworks use the same family of Mobius transformations to map between a material/field property and a measurable response.

CASCADE — Reflection Coefficient (Step 10) Γ(r, d) = (ar · (d + 0.5) − 1) / (ar · (d + 0.5) + 1)
r = ray index (0–11), d = pi digit (0–9)
ar = impedance parameter per ray
120 unique values = 12 rays × 10 digits
Textbook — Clausius-Mossotti (Eq 20.17, p.481) (ε − 1) / (ε + 2) = (1 / 3ε0) ∑ Niαi
ε = dielectric constant
Ni = number density of type i
αi = polarizability of type i

Shared structure

General Cayley transform f(x) = (x − 1) / (x + k)

Clausius-Mossotti: k = 2, x = ε. Maps dielectric constant → polarizability density.
CASCADE: k = 1, x = ar·(d+0.5). Maps field impedance → reflection coefficient.

Fixed point: f(x) = 0 when x = 1 (matched impedance / zero reflection).
Pole: f(x) → ∞ when x = −k (ferroelectric divergence / total reflection).

The Lorentz local field correction

The textbook derives the (x+2) denominator from the Lorentz cavity correction (p.479, Fig 20.4): the field at a dipole inside a polarized medium is not the applied field F, but:

Fi = F + P / (3ε0)

This correction transforms the linear response ε−1 = Nα/ε0 into the nonlinear Cayley form. In CASCADE, the half-integer shift (d+0.5) plays the same role — it corrects the raw digit for the local field environment before the transform is applied.

Confirms: The gamma function is not ad hoc — it is the standard Cayley transform used in dielectric physics since 1879 (Clausius) and 1850 (Mossotti). The Lorentz correction that produces the denominator is derived from electrostatics of a cavity in a polarized medium.
